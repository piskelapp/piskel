## Keeping docs accurate

- Update docs in the same change as the code they describe.
- Point to code instead of copying it: name the file that holds a fact
  (script list, commands, settings defaults) rather than repeating its
  contents, and avoid line numbers, counts and version numbers.
- Mark anything uncertain with _(to confirm)_ instead of guessing.
- Prefer few, short documents: every sentence is something that can go
  stale.
